# Estudio Stock

Inventario movil para material de tatuaje.

## Uso

- Crea materiales desde el boton `+`.
- Ajusta stock con `-` y `+`.
- Selecciona materiales y usa `Borrar seleccion`.
- Usa `Compra` para ver lo que falta segun el minimo.
- Usa `Ticket OCR` para leer tickets con camara/imagen y aprender precios por proveedor.
- Usa `Preparar compra` para separar la compra entre AtomX, Vega Tattoo y pendientes.

La app guarda los datos en el navegador del movil.
